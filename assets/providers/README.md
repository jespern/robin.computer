# Provider marks

Original assets fetched from the providers' own websites on 2026-11-18, stored
locally so visitors make no third-party requests. Source URLs and SHA-256
digests are in `sources.json`. Colours and shapes are unchanged; CSS scales
each mark proportionally. The SVGs contain no scripts, external references or
embedded documents. No icon package or runtime dependency is used.

- Gmail and Google Calendar: current product marks linked by workspace.google.com.
- Fastmail: the icon served by its official site, also linked from its media kit.
  https://www.fastmail.com/media-kit/
  https://www.fastmail.com/policies/brand-guidelines/
- Slack: the full-colour mark from Slack's own marketing CDN.
  https://api.slack.com/media-kit
- Telegram: official SVG. https://telegram.org/tour/screenshots
- WhatsApp: its official 192px web-app touch icon.
  https://web.whatsapp.com/
- Google Workspace and Google Routes: the current Google G, with the product
  name alongside it. This is a Google brand mark, not a claimed separate Routes
  or Workspace product icon.
- Google Weather: an official Weather API condition illustration, with the
  product name alongside it; not a separate Google Weather brand logo.
  https://developers.google.com/maps/documentation/weather/weather-condition-icons

These marks identify current or planned sources, not endorsements. Keep the
current/planned labels with the provider names and the Fastmail credit in the
footer. Provider trademarks remain their owners' property.
